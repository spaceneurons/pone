# Вкусный След — V6

Четыре страницы по исходным макетам Figma: главная, готовые фудбоксы, меню-конструктор, карточка товара. Основной интерфейс — интерактивные HTML-страницы с исходными SVG-слоями и JavaScript.

## Запуск

Node.js 18+; в распакованной папке выполните `npm start`, откройте http://127.0.0.1:3000. Установка npm-зависимостей для этого режима не требуется. Для визуального просмотра можно открыть `preview.html`, но для заявок нужен сервер. Интернет нужен для загрузки веб-шрифтов.

## Каталог и будущая админка

`public/catalog-data.json` — источник данных; ключ объекта — постоянный ID товара, `name`, `price`, `min`, `image`, `kind` — название, цена, минимальное количество, фото и тип блюда. `tags` — массив признаков. `demoMetadata`, `demoTags`, `demoKinds` — отдельные временные поля. `npm run seed:demo` генерирует воспроизводимые псевдослучайные демо-признаки и синхронизирует `public/catalog-data.js` для браузера. В реальной админке записывайте проверенные `tags` и `kind`, выключайте `demoMetadata` и удаляйте временные поля; генератор больше не нужен. Сами данные о составе, типе и цене не изменены. Демо-фильтры не предназначены для реальных пищевых ограничений; в интерфейсе есть предупреждение. Фильтр «До 3 Br» всегда использует цену за единицу; готовые боксы дороже 3 Br, поэтому там результат пустой. При объединении фильтров также возможен пустой результат.

## Заявки и заказы

Telegram отключён. Сервер валидирует заявку и сохраняет её в `data/submissions.jsonl`, включая время, контактные данные и позиции заказа. Папка закрыта от HTTP-доступа и исключена из Git. Не публикуйте файл с персональными данными. Для реального запуска понадобится защищённое хранение, политика обработки и управление доступом. Заказы принимаются с 09:00 до 23:00 по Europe/Minsk; сервер повторно проверяет время и цены.

## Проверки

`npm test` — проверка синтаксиса. Проверены совпадение JSON/JS каталога, наличие всех демо-категорий и сохранение валидной тестовой заявки через HTTP без Telegram; тестовые данные удалены. Полный браузерный тест и React-сборка не выполнены. React-исходники оставлены от предыдущих версий; используйте основной режим `npm start`.
